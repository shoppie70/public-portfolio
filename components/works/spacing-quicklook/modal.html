Tailwind CSS Spacing Size QuickLook

「Tailwind CSSの余白クラスを即座に参照・コピー。デザインと実装の共通言語化を支えるChrome拡張機能」

🔗 Chrome ウェブストア →

転職先でTailwind CSSをチームに浸透させる際、フォントサイズに続き「余白クラス（p-4 や m-6 等）と具体的なピクセル数値の相互変換」も開発スピードを左右する課題でした。その脳内変換オーバーヘッドをゼロにし、チーム全員がスムーズに実装できるよう開発したChrome拡張機能シリーズの第2弾です。

【組織への影響・開発効率の向上】
余白数値（px / rem）の即座な参照に加え、クラス名のワンクリックコピー機能を搭載。エンジニアチーム内のコーディングスピード向上と、デザイナーとの余白指定におけるコミュニケーションコスト大幅削減に貢献しました。

主な機能:
  • 一瞬で余白数値を参照＆コピー: ツールバーのポップアップからワンクリックで余白クラス・rem値・px換算値を表示し、即座にクリップボードへコピー可能。
  • 超軽量ノーライブラリ実装: 外部依存を一切排除したVanilla JSのみで構成し、ブラウザのパフォーマンスを害さない快適な動作環境を実現。
