受診メモ生成ツール

「病院での『伝え忘れ』『聞き忘れ』をゼロにする、A4印刷対応の受診メモ作成ツール」

🔗 サイトにアクセスする →

短時間で行われる診察の問診で、伝えたい症状・経過・アレルギー・既往歴をあらかじめ整理し、医師や看護師にそのまま渡せる印刷用メモを1分で生成するWebアプリケーション。

課題解決・UXへのこだわり:
  • 1分で要点を整理: 主訴・発症時期・症状の変化・服薬状況・医師への質問などを標準的な問診フォーマットに沿って入力するだけで、医師に伝わる構成に自動整形。
  • A4・1枚に最適化されたプリントレイアウト: リアルタイムプレビューで仕上がりを確認しながら、ブラウザの印刷機能で用紙1枚にぴったり出力。PDF保存やスマホ画面での提示にも対応。
  • 完全ローカル保存・安心のプライバシー: 入力された医療・健康データは外部サーバーへ一切送信されず、すべてブラウザの localStorage のみに安全保存。
  • 乳幼児対応＆入力補助: 乳幼児モード（体重の g 表示切り替えや生後日数・月数の自動計算）やクイック入力チップなど細やかな配慮を実装。
技術的工夫:
  • React 19 & TypeScript 6 による堅牢な設計: 最新のReactおよびTypeScriptを採用し、フォーム状態管理とリアルタイムプレビューを型安全かつスムーズに構築。
  • Tailwind CSS v4 活用: 最新のTailwind CSS v4を使用したレスポンシブかつスタイリッシュなコンポーネントデザイン。
  • Cloudflare Pages によるエッジ配信: 静的ホスティング基盤としてCloudflare Pagesを利用し、高速かつ安定した配信を実現。
