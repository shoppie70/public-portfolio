不動産契約書作成システム

「手作業のExcel転記コストをゼロへ。Laravelで契約書類を一括自動生成する不動産業務DXシステム」

【開発背景・課題解決】
保守運用契約を結んでいる不動産会社（ひまわり建宅様）より、「顧客ごとに手作業でExcel作成・管理している契約書類の作成業務を自動化したい」という要望を受け開発。 手入力による転記ミスやフォーマット不備を防止し、契約書類作成にかかる業務工数の大幅な削減を実現しました。

【担当領域】
フルスタック開発（要件定義 / DB設計 / UI・UXデザイン / バックエンド・フロントエンド実装 / テスト / 導入・運用支援）

主要機能:
  • 契約・物件データの一元管理: 物件情報（設備・配管等）、貸主、入居者、契約条件（賃料・敷金・日割り計算）の登録管理。論理削除（SoftDeletes）による変更履歴保持に対応。
  • Excel帳票自動出力エンジン: 登録データを取り込み、既存のフォーマットに沿った各種書類（賃貸借契約書、重要事項説明書、入居申込書、ライフライン案内書等）をExcel形式（.xlsx）で一括自動生成。
設計・アーキテクチャの工夫:
  • UseCaseパターンによるドメイン分離: 業務ロジックや帳票生成をUseCaseクラス（ExportContractAction 等）に集約し、Controllerを軽量化。保守性の高い堅牢なアーキテクチャを採用。
  • 帳票出力モジュールの抽象化: PhpSpreadsheetを用いたExcelマッピング処理を共通化・抽象化し、帳票テンプレートの追加や様式変更に柔軟に対応できる構造を構築。
  • 自動テスト（PHPUnit）による品質担保: 核心となるAPIおよびUseCase層に対してUnit/Featureテストを実装し、継続的な保守運用における信頼性を確保。

技術スタック

PHP 8.3 / Laravel 11 Blade / Tailwind CSS / Alpine.js / Vite MySQL / PhpSpreadsheet PHPUnit / Docker Compose
