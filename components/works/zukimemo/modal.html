【開発背景・ユーザーの課題解消】
「頭が割れそうな時に複雑な操作をさせないでほしい。医師に見せる体調データ出力にお金を取らないでほしい。」 いち頭痛持ちとしての切実な不満から開発した頭痛管理アプリ。既存アプリの「服薬データの紐付け表示バグ」や「PDFエクスポートの有料制限」を根本から解消し、痛い時でも1〜2タップで記録が完了する完全無料のツールを自律開発しました。

主な特徴・家族を支えるプロダクト価値:
  • ファミリーリンク（パートナー共有機能）: パートナーのアカウントと紐付けることで、互いの体調や服薬状況をリアルタイム共有。夫婦間での体調可視化により、シフト制での乳児の育児・お世話の連携プレイをシステム面から強固にサポート。
  • 気圧自動連動＆医師提示用PDFエクスポート: Geolocation APIと気象情報APIを連携させ、記録時の「気圧(hPa)・天気・気温」を自動補完。受診時にそのまま医師へ手渡せるA4サイズの診察用PDFレポートやCSVデータを完全無料で出力可能です。

【技術スタック＆アーキテクチャ】
Laravel 12 + Inertia.js + React + Tailwind CSS + shadcn/ui によるモダンモノリス構成（PWA対応）。headache_logs と medication_logs をDBレベルで厳格に分離することで表示バグを構造的に排除し、将来のReact Native（iOS/Android）アプリ化も見据えた拡張性の高い設計を採用しています。
